# Task 25 - ReactJS Hooks

ReactJS online shoe store for Task 25.

## Features
- Shoe collection with image, name and price
- Shopping cart on the right
- Add to Cart using React `useState`
- Increase/decrease quantity
- Remove item when quantity reaches zero
- Dynamic cart total
- Home, Categories and About Us navigation
- Responsive design

## Run
```bash
npm install
npm run dev
```
